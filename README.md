Here is a repository of Leetcode solved tasks:

* EASY best time to buy and sell stocks (https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/)
* EASY two sum (https://leetcode.com/problems/two-sum/description/)
* EASY merge two sorted lists (https://leetcode.com/problems/merge-two-sorted-lists/description/)

Requires CMake 3.30+ and C++20.
To build: 
  * cmake . -B build
  * cmake --build ./build

To run tests:
  * ctest --test-dir build
